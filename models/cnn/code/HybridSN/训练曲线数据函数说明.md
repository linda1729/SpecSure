# 训练历史数据保存功能

## 概述

在训练过程中，系统会自动收集并保存 Train Loss、Train Accuracy、Valid Loss 和 Valid Accuracy 数据，用于绘制训练曲线。

## 功能说明

### 1. 函数定义

**位置**：[utils.py](utils.py)

**函数签名**：
```python
def save_training_history(history, save_path):
    """
    保存训练历史数据到txt文件
    
    Args:
        history: dict，包含 'train_loss', 'train_acc', 'valid_loss', 'valid_acc' 的列表
        save_path: str，保存路径
    """
    os.makedirs(os.path.dirname(save_path), exist_ok=True)
    with open(save_path, 'w') as f:
        f.write('epoch,train_loss,train_acc,valid_loss,valid_acc\n')
        for i in range(len(history['train_loss'])):
            f.write(f"{i+1},{history['train_loss'][i]:.6f},{history['train_acc'][i]:.6f},")
            f.write(f"{history['valid_loss'][i]:.6f},{history['valid_acc'][i]:.6f}\n")
```

**功能描述**：
- 将训练过程中每个epoch的loss和accuracy数据保存为CSV格式的txt文件
- 自动创建必要的目录结构
- 数据格式规范化，便于前端绘制图表

### 2. 调用位置

**位置**：[train.py](train.py) 中 `train()` 函数

**调用时机**：在保存测试报告后立即调用

**调用代码**：
```python
# 保存训练历史
history_name = f"{dataset_name}_history_{suffix}.txt"
history_path = os.path.join(report_dir, history_name)
save_training_history(history, history_path)
print(f'Training history saved to: {history_path}')
```

### 3. 数据收集

在训练循环中的每个epoch，系统会自动记录：

```python
history = {
    'train_loss': [],
    'train_acc': [],
    'valid_loss': [],
    'valid_acc': []
}

for epoch in range(1, args.epochs + 1):
    train_loss, train_acc = train_epoch(...)
    valid_loss, valid_acc, _, _ = eval_epoch(...)
    
    # 记录训练历史
    history['train_loss'].append(train_loss)
    history['train_acc'].append(train_acc)
    history['valid_loss'].append(valid_loss)
    history['valid_acc'].append(valid_acc)
```

## 输出文件格式

### 文件名规则

```
{数据集完整名称}_history_pca={K}_window={窗口大小}_lr={学习率}_epochs={训练轮数}.txt
```

### 文件名示例

- `IndianPines_history_pca=30_window=25_lr=0.001_epochs=10.txt`
- `Salinas_history_pca=15_window=25_lr=0.001_epochs=100.txt`
- `PaviaU_history_pca=15_window=25_lr=0.001_epochs=50.txt`

### 文件保存位置

```
models/cnn/reports/HybridSN/
```

### 文件内容格式

CSV格式，包含表头和数据行：

```
epoch,train_loss,train_acc,valid_loss,valid_acc
1,0.234567,0.891234,0.456789,0.876543
2,0.198765,0.912345,0.398765,0.901234
3,0.187654,0.923456,0.376543,0.912345
...
```

**字段说明**：
- `epoch`：训练轮次（从1开始）
- `train_loss`：该epoch的训练集损失值
- `train_acc`：该epoch的训练集准确率（0-1之间）
- `valid_loss`：该epoch的验证集损失值
- `valid_acc`：该epoch的验证集准确率（0-1之间）

## 使用方法

### 自动保存

训练过程中无需额外操作，系统会自动：
1. 在每个epoch收集loss和accuracy数据
2. 训练完成后保存为txt文件

### 手动读取

前端或其他应用可以：

1. **Python读取**：
```python
import pandas as pd

history_file = 'IndianPines_history_pca=30_window=25_lr=0.001_epochs=100.txt'
df = pd.read_csv(history_file)

# 绘制Loss曲线
import matplotlib.pyplot as plt
plt.plot(df['epoch'], df['train_loss'], label='Train Loss')
plt.plot(df['epoch'], df['valid_loss'], label='Valid Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.show()

# 绘制Accuracy曲线
plt.plot(df['epoch'], df['train_acc'], label='Train Accuracy')
plt.plot(df['epoch'], df['valid_acc'], label='Valid Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.show()
```

2. **前端JavaScript读取**：
```javascript
fetch('history_file.txt')
  .then(response => response.text())
  .then(data => {
    const lines = data.trim().split('\n');
    const headers = lines[0].split(',');
    const values = lines.slice(1).map(line => {
      const row = {};
      line.split(',').forEach((val, i) => {
        row[headers[i]] = parseFloat(val);
      });
      return row;
    });
    // 使用values数据绘制图表
  });
```

## 参数配置说明

文件名中的参数含义：

| 参数 | 含义 | 示例 |
|------|------|------|
| `pca=K` | PCA降维后的维度数 | `pca=30` (IndianPines), `pca=15` (其他) |
| `window=size` | 样本块的窗口大小 | `window=25`, `window=11` |
| `lr=学习率` | 模型训练的学习率 | `lr=0.001`, `lr=0.0001` |
| `epochs=轮数` | 总训练轮次 | `epochs=10`, `epochs=100` |

## 数据集与参数映射

| 数据集缩写 | 完整名称 | 默认PCA维度 | 默认输出单元数 |
|----------|---------|----------|-------------|
| IP | IndianPines | 30 | 16 |
| SA | Salinas | 15 | 16 |
| PU | PaviaU | 15 | 9 |

## 注意事项

1. **数据精度**：Loss和Accuracy值保留6位小数，便于精确分析
2. **epoch编号**：从1开始，与训练日志保持一致
3. **文件编码**：使用UTF-8编码，兼容各种系统
4. **目录自动创建**：保存路径不存在时会自动创建

## 常见问题

**Q：如果中途停止训练，历史数据会保存吗？**
A：不会。历史数据在训练完全结束后才会保存。如果需要保存中间过程，可以修改代码在每个epoch后定期保存。

**Q：能否修改保存频率？**
A：可以。修改[train.py](train.py)中的history保存逻辑，如改为每N个epoch保存一次。

**Q：如何与其他指标组合分析？**
A：可以读取history文件和report文件，结合其他工具进行数据分析和可视化。
