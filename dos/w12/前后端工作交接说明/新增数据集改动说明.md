## 新增数据集需要修改的内容（后端 + 目录）

当前系统仅支持预置 IP/SA/PU，若要扩展新数据集，请按如下步骤：

1) 数据文件与目录  
   - 在项目根 `data/` 下创建新数据集目录，如 `data/NewSet`。  
   - 放置 `HSI` 与 `GT` 的 `.mat` 文件，命名自定但需在配置中保持一致。  
   - 可选：添加 `NewSet.CSV`（第一列 class id，第二列名称）以便可视化显示类别名。

2) 后端配置（必改）  
   - 编辑 `backend/app/core/config.py`：在 `BASE_DATASET_DEFINITIONS` 中新增条目，字段示例：  
     ```python
     "NS": {  # 数据集 ID
         "name": "NewSet",
         "folder": "NewSet",
         "data_file": "NewSet_hsi.mat",
         "data_key": "<hsi_key_in_mat>",
         "gt_file": "NewSet_gt.mat",
         "gt_key": "<gt_key_in_mat>",
     },
     ```
   - 确认 `DATASET_SLUG_TO_ID` 能包含新键；添加后自动合并。

3) CNN 侧数据工具  
   - `models/cnn/code/HybridSN/utils.py`：在 `REQUIRED_FILES`、`DATASET_FOLDERS`、`DATA_KEYS` 中加入新数据集的文件名和键名，确保 `resolve_data_path`、`verify_dataset_files`、`load_data` 能识别。  
   - 如有特定类别数或输出维度，请在 `load_dataset` 中根据数据集 ID 设置 `output_units`。

4) SVM 侧数据工具  
   - `models/svm/code/SVM/utils.py`：在 `REQUIRED_FILES`、`DATASET_FOLDERS` 中增加新数据集的文件名映射。  
   - `models/svm/code/SVM/train.py`：在 `REQUIRED_FILES`/`DATASET_FOLDERS` 中同步新增，确保路径解析 `_resolve_base_paths`、数据载入 `load_hsi_gt` 可找到文件。

5) 前端适配  
   - `mockfrontend/app.js` 依赖后端 `/api/cnn/defaults` 的 `datasets` 列表自动渲染，不需硬编码 ID；如需默认模型提示，可在 `CNN_MODEL_HINTS`/`SVM_MODEL_HINTS` 中按需补充。
   - 若新增数据集模型命名不符默认规则（`<Folder>_model_pca=...`），需在前端或后端调整自动匹配逻辑。

6) 检查与验证  
   - 确认 `data/<NewSet>` 下 `.mat` 文件与配置一致，键名正确可被 `loadmat` 读取。  
   - 运行一次训练确保报告、可视化、模型均能生成，并在前端“产物/评估”页面正常展示。  
   - 留意 PCA 维度和窗口大小默认值，可在前端表单手动调整。

## 约定与命名

- 模型命名沿用 `<Folder>_model_pca=<K>_window=<w>_lr=<lr>_epochs=<e>.(pth|joblib)`，以便前端/后端自动匹配。  
- 可视化与报告会按照相同参数生成文件名，新增数据集保持该规则即可被自动列出与解析。
