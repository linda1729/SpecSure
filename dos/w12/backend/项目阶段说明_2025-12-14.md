启动后端：`uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000`  
启动前端：在 mockfrontend 下 `python -m http.server 5500`，访问 `http://localhost:5500/`（默认使用本地后端，需公网可加 `?api=http://8.140.214.49:8000`）。

当前进度（后端 / 前端简版）：
- 数据：支持 IP/SA/PU，就绪检测依赖 data/ 目录；自定义上传入口已移除。
- 模型：CNN HybridSN、SVM 训练/推理均可运行；推理自动匹配最新模型（过滤 .pca.pkl）。
- 产物/评估：报告、混淆矩阵、预测/GT/伪彩/分类/误差图自动列出，评估页支持 CNN/SVM 对比。
- 前端：参数填写、训练/推理、产物列表、评估对比、日志/进度可用，默认 API 改为本地。

风险与待办：
- 仅支持预置数据集，若扩展需修改 config 与 utils（详见交接文档）。
- 本地需自备 .mat 数据与模型文件，否则推理会提示缺模型。
- 若更换命名规则，需同步更新前端默认模型提示或后端匹配逻辑。
